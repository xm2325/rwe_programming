# Restoration provenance

This repository is a **reconstructed public portfolio** based on archived application artefacts from August 2026. The original local project package/source archive was not found in the ChatGPT File Library or connected GitHub account during restoration.

Archived artefacts document the following original portfolio claims:

- synthetic longitudinal gout cohort with 9,184 patients;
- explicit cohort/exposure/outcome/time-zero/follow-up definitions;
- propensity-score estimation with stabilised IPTW;
- weighted Cox survival analysis;
- balance/positivity diagnostics;
- SQL and pandas patient-level reconstruction checks;
- OMOP-shaped representation checks;
- sensitivity analysis for propensity-score specification, weight restriction, missingness, bootstrap uncertainty, proportional hazards, negative controls and outcome definitions;
- prior release evidence recorded 52 tests and 60 runtime QC checks.

The code in this repository is a fresh reconstruction and **must not be represented as byte-for-byte recovery of the original v0.4.x/v0.5.x source**. Historical numbers are kept separate from currently executable results.
